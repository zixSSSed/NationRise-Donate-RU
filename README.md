# NationRise — магазин, зеркало на .ru

Полная копия донат-магазина, размещённая на **GitHub Pages** и привязанная
к домену **nationrise.ru**.

Основная площадка — [nationrise.space](https://nationrise.space) (Cloudflare Pages),
репозиторий [NationRise-Donate](https://github.com/zixSSSed/NationRise-Donate).

## Зачем зеркало

Запасной вход на случай, если основной домен не открывается у части игроков.
GitHub Pages — другая инфраструктура и другие адреса, поэтому доступность
не зависит от основной площадки.

## Чем отличается от основного сайта

Ничем — файл `index.html` побайтово тот же. Он сам определяет, откуда открыт:

- на `nationrise.space` оплата идёт в свою серверную функцию `/api/pay`;
- на зеркале функций нет (GitHub Pages отдаёт только статику), поэтому запрос
  уходит на `https://nationrise.space/api/pay`, которому это разрешено;
- если и основной домен недоступен, показывается ссылка на витрину EasyDonate
  (задаётся в `CONFIG.SHOP_FALLBACK_URL`).

## Обновление зеркала

После правок в основном репозитории скопировать сюда `index.html` и `img/`,
не трогая `CNAME`, затем закоммитить и запушить.
